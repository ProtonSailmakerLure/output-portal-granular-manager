## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Preset Library** | Organize Portal presets by granular character and effect style |
| **Scan Config** | Document scan speed and direction settings per preset |
| **Texture Notes** | Track spray, size and pitch settings for key granular presets |
| **Style Tags** | Tag Portal presets by genre and production application |
